# Mortgage Loan Performance Analysis

## Project Status
In Progress

## Objective
To analyze a sample mortgage loan portfolio and understand loan balances, loan distribution, and portfolio performance using data analytics tools.

## Tools
- Microsoft Excel
- SQL
- Power BI

## Planned Analysis
- Total number of mortgage loans
- Total original loan amount
- Total outstanding loan balance
- Loan distribution by state and loan type
- Key portfolio trends and insights

## Dataset
A synthetic dataset will be created for learning and portfolio demonstration. It will not contain real customer or employer information.

## Progress
Project setup started. Dataset preparation and analysis are upcoming.
