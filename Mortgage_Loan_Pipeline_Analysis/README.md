# Mortgage Loan Pipeline & Operational Performance Analysis

## Project Overview

This project analyzes 5,000 fictional mortgage application records using Microsoft Excel 365.

The objective is to evaluate mortgage application pipeline performance, funding activity, lender volume, and operational performance through interactive dashboards and supporting analytical reports.

## Business Objectives

- Analyze monthly mortgage application and funding trends.
- Measure funded loan volume and total funded loan amounts.
- Compare lender performance.
- Analyze loan purpose and loan type distributions.
- Evaluate loan officer and loan processor performance.
- Build an interactive executive dashboard.

## Dataset

- Total records: 5,000
- Industry: Mortgage lending
- Geography: United States
- Dataset: Fictional synthetic data created for portfolio demonstration.

## Executive Dashboard

The interactive Excel dashboard includes:

- Four KPI cards.
- Six PivotCharts.
- Lender Name slicer.
- State slicer.
- Loan Type slicer.
- Application Status slicer.

The Application Status slicer filters the charts while preserving the overall KPI denominator, preventing misleading changes to the funding rate.

## Key Findings

- 2,398 of 5,000 applications were recorded as funded, representing a 47.96% funding rate.
- Total funded loan amount was $1.14838 billion.
- 2025 funded loan amount was $683.695 million.
- 2026 funded loan amount was $464.685 million through November 2, 2026.

## Data Quality and Limitations

- 2,602 records have blank Funded Date values.
- These records were retained in the source dataset and excluded from funded-date-based analysis.
- November 2026 is a partial reporting period through November 2.
- December 2024 applications are retained as a separate carryover period.
- All records are synthetic and do not represent actual customer or company information.

## Multi-Tool Analytics

This mortgage analytics initiative is designed as a unified, cross-platform business analytics project.

The Excel implementation establishes the baseline business metrics and analytical findings. The same synthetic dataset and business objectives will support complementary analysis, data modeling, interactive visualizations, and business intelligence reporting across Power BI, Tableau, Python, and SQL.

Each implementation will provide additional analytical perspectives and demonstrate the application of different technologies to business problems.
